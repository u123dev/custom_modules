# Hr Hospital Module

## Module for hospital automation - keeping records of doctors and patients.

Module name:  **hr_hospital**  

List of entities:
- Doctor 
- Patient
- Types of diseases
- Patient visits

Features:
- module menu with submenu items
- views: form and tree
- full access rights to new model records for the user group "base.group_user".

"master" data:
- 3 records for the model "Disease type"

"demo" data:
- 3 records for the "Doctor" model (specifying the observing doctor)
- 3 records for the "Patient" model
